Use the Playbook in Your AI Assistant

Point your own AI assistant at the playbook's public MCP server and it can look up pricing tiers, engagement phases and Customer Zero guidance on your behalf — without you leaving your editor, your chat window, or Copilot Studio.

Public, read-only No sign-in required

The playbook runs its own Model Context Protocol (MCP) server. Connect it to Claude, VS Code, Cursor, or Microsoft Copilot Studio, and your assistant gains one new capability: it can search the pages of this site and bring back the answer, with a source link, instead of you switching tabs to search it yourself.

What is MCP?

MCP is an open protocol that lets an AI assistant call tools hosted on a server it did not build. Your assistant sends a request to the playbook's server, the server searches the published pages and returns matching passages, and your assistant folds the answer into its reply.

The server URL

Every client below uses this same address. Copy it once and paste it into the setup step for your client.

https://143cf7a6-834c-406c-b5ea-62e00f4de7bd.search.ai.cloudflare.com/mcp

The server exposes exactly one tool, search. It takes a query, searches the playbook's published pages, and returns the matching passages with their source URLs. It cannot write, modify, or see anything outside those pages.

Setup, by client

Claude (claude.ai and Claude Desktop)

  1. In Claude, go to Settings > Connectors (on a Team or Enterprise plan, an owner adds it first under Organization settings > Connectors, then members connect to it).
  2. Click Add, then Add custom connector.
  3. Name it (for example Copilot Playbook) and paste the server URL above, then Continue.
  4. On the authentication step, choose No sign in — the server takes no credentials.
  5. Click Add. Claude Desktop uses the same remote-connector flow, since the connection runs from Anthropic's infrastructure rather than your device.

Verified against Claude Help Center: Get started with custom connectors using remote MCP, current as of this page's last update.

VS Code with GitHub Copilot

  1. Create .vscode/mcp.json in your workspace (or run MCP: Open User Configuration for a config that follows you across projects).
  2. Add the server under the top-level servers key:
{
  "servers": {
    "playbook": {
      "type": "http",
      "url": "https://143cf7a6-834c-406c-b5ea-62e00f4de7bd.search.ai.cloudflare.com/mcp"
    }
  }
}
  1. Open Copilot Chat in agent mode. VS Code starts the server automatically; use Configure Tools to confirm search is enabled.

Verified against VS Code docs: Add and manage MCP servers in VS Code, current as of this page's last update.

Cursor

  1. Create .cursor/mcp.json in your project (or ~/.cursor/mcp.json to make it available in every project).
  2. Add the server:
{
  "mcpServers": {
    "playbook": {
      "url": "https://143cf7a6-834c-406c-b5ea-62e00f4de7bd.search.ai.cloudflare.com/mcp"
    }
  }
}
  1. Save the file. No headers entry is needed — the server is public.

Verified against Cursor docs: Model Context Protocol (MCP), current as of this page's last update.

Microsoft Copilot Studio

  1. On your agent's Tools page, select Add a tool > New tool > Model Context Protocol.
  2. Fill in Server name (for example Copilot Playbook), a one-line Server description, and the Server URL above.
  3. For authentication, choose None — the server requires no sign-in.
  4. Select Create, then Create a new connection and Add to agent.

Copilot Studio only supports the Streamable HTTP transport for MCP (it dropped SSE after August 2025); this server speaks Streamable HTTP, so no extra configuration is needed.

Verified against Microsoft Learn: Connect your agent to an existing MCP server, current as of this page's last update.

Before you quote a customer

This server is public and read-only. It answers only from the pages already published on copilotplaybook.com, the same content anyone can read here directly — it cannot see your tenant, your deals, or anything else. Always confirm pricing and licensing with Microsoft before quoting a customer.
