Add real Yahoo draft data (optional, free)

The ADP shipped with this board comes from about 7,800 mock drafts. Yahoo publishes ADP from real completed drafts on your own platform, plus a last-seven-days column — which is live market movement, the one thing a static file cannot give you. It costs nothing and takes a minute.

  1. In your league, click Draft in the top nav, then Draft Analysis. You do not need to be the commissioner — it is visible to every league member, and the address ends /draftanalysis.
  2. It shows thirty at a time, so use the position chips along the top — QB · RB · WR · TE · K · DEF — and do one at a time. Six pastes covers the top thirty at every position, which is more of the board than paging the combined list would give you.
  3. For each: select all, copy, paste below, Add this page. They accumulate.

For QB, RB, WR and TE you can jump straight there by adding ?pos=RB to the address. The K and DEF pages need the chip clicked — that URL parameter comes back empty for them.

Yahoo's page says “ADP based on standard scoring settings”, so these are not your league's PPR numbers. They are worth having for where the room actually takes people and for which way a player is moving this week — not as a ranking. The board keeps using its own scoring for that.

Draft style

Every style is a set of adjustments to the same scoring engine. You can see exactly which ones, and exactly who moves because of them.

See what a style actually builds

Runs a full mock draft from where you are now against a modeled room — the same one the practice run drafts against. Every other team draws near a player's real draft position using that player's own spread, obeys the same position limits you do, and starts from the roster it has actually built so far. It shows the roster each style leaves you holding. Pick two to compare them side by side — both get the identical sequence of opponent picks, so any difference is the style rather than luck.

Describe it in your own words

Tell Claude how you want to draft and it proposes the adjustments. Nothing is applied until you look at what changed — and every value it returns is checked against a whitelist and clamped to a sane range before the board ever sees it. A model suggesting numbers is a suggestion, not an instruction.

Two ways in

Practice the whole thing first, then run it for real on the night.

How a practice run works

  1. Hit Simulate. The room drafts, pick by pick, until the pick is yours. It always stops on you — it never drafts your team for you.
  2. Make your pick. Same board, same suggestions, same two-minute clock. DRAFT on a row puts him on your roster.
  3. Hit Simulate again. The room runs on to your next pick. Repeat to the end of the fifteenth round.
  4. Start over when you are done, or Reset draft in League setup, which clears every simulated pick. Undo works on any single one.

What the room is actually doing

Not "take the top of the list". Every team draws near a player's real draft position using that player's own spread, so consensus picks go where they always go and late-round darts land anywhere across two rounds. Teams obey the same position limits you do — nobody takes a third kicker — and they lean into a positional run once one starts, the way a real room does.
